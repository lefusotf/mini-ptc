# Sistema Clínica (estilo del ejemplo del profe)

```
Sistema Clinica.sln
BaseDeDatos/ClinicaDB.sql            ← ejecutar en SQL Server Management Studio
Modelos/Conexion_DB/Conexion.cs      ← servidor (localdb)\MSSQLLocalDB
Modelos/Entidades/                   ← Paciente, Medico, Cita, Historial, Usuario...
Vista/Login, Vista/Dashboard, Vista/Gestion
Documentacion/Documentacion_Clinica.docx
```

1. Ejecutar `BaseDeDatos/ClinicaDB.sql` (F5).
2. Abrir `Sistema Clinica.sln`.
3. Clic derecho en **Vista** → *Establecer como proyecto de inicio* → F5.
